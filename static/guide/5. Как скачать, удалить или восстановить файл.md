Для скачивания одного файла нажмите значок загрузки справа в его строке. Кнопка **«Скачать все»** скачивает архив.

Для удаления нажмите **«Удалить файлы»**, отметьте нужные строки и подтвердите удаление той же кнопкой.

Удалённые файлы доступны через фильтр **«Удалённые»**. Нажмите **«Восстановить»**, чтобы вернуть файл и повторно проверить его. Свободный слот может быть использован для новой загрузки.
