Это сообщение появляется, если вы загрузили файл с группами, расписание которых уже есть в другом файле. Конфликт также возникает, если название группы в загруженном файле совпадает с названием группы в другом файле.

Чтобы оставить актуальное расписание, удалите старый файл с дублирующимися группами. Перед удалением убедитесь, что в нём нет расписания других групп, которое нужно сохранить.

Как удалить старый файл:

1. На странице расписания выберите фильтр **«Все»** и найдите старый файл с дублирующимися группами.
2. Нажмите **«Удалить файлы»**.
3. Отметьте флажок справа в строке старого файла.
4. Нажмите ту же кнопку ещё раз — теперь на ней будет написано **«Удалить»** и показано количество выбранных файлов.
5. Дождитесь обновления списка и статусов файлов.

Если кнопка удаления недоступна во время загрузки, дождитесь её завершения.

Если вы ошиблись при удалении, откройте фильтр **«Удалённые»** и нажмите **«Восстановить»** рядом с нужным файлом.
